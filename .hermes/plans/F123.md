Status: done · Brief v2 · written by hx from hx.db; edit the plan in hx, not here.

**Goal:** A fast inference path for the L+2 learned block heads T0 and T3 that has the serving scorer's shape. It takes the inputs serving already holds on the device: the biased fp32 target-gate scores, bf16 x and the source layer's routes and route weights. It produces the same cap-1 read the frozen F109 reference would make. Alongside it: - a measured per-component cost breakdown and the incremental cost over the native score+select kernels, under CUDA graphs at live widths 1-6; - a side-stream interference measurement; - read-set parity against the frozen F109 thresholds on every dev and calib group. Nothing is wired into serving. That is Stage 3.
