# F109 · L+2 learned heads vs native gate under the serving read policy (Stage 1)

Status: done · Brief v2 · written by hx from hx.db; edit the plan in hx, not here.

**Goal:** An offline comparison, on the reused B0/B1 corpus, of native-gate L+2, T0 L+2 and T3 L+2. It uses the serving policy: a hard cap of one unique expert read per target layer per forward, plus a pre-registered sweep of mean-read budgets that allows the policy to abstain. Every number is computed on identical groups, residency snapshots, exclusions and denominators. The output names one frozen candidate policy per scorer for a later served comparison. It trains nothing and reads nothing from the locked test split.
