# F100 · Track B0: DSV4.1 gate training capture for a learned L+1..L+4 predictor

Status: done · Brief v5 · written by hx from hx.db; edit the plan in hx, not here.

**Goal:** A session-split DSV4.1 training corpus, captured on the served EXL3 fused path with the production recipe and prefetch off, that holds for every (verify forward, layer, token) the gate input, native routes and weights, the device RAM map of the next four layers at the prediction point, and each routed lane's true demand kind, with timestamps, identity, an integrity report and a manifest. It is what Track B1 (baselines, E2/E5, L+1 and L+2/L+4 evaluation) trains and tests on.
