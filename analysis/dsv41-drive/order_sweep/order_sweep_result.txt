THE ONE REAL HIT (latent: neither the pytest order nor CI's alphabetical order triggers it)
  test_server_args.py::TestMultimodalFeatureTransport::test_default_transport_is_cpu_for_unsupported_multinode_model
  fails when TestNoneMeansUnset runs before TestMultimodalFeatureTransport (found by pairing each class that sorts after
  it with the failing test): "'has not opted into CUDA VMM' not found in ... SGLANG_USE_CUDA_IPC_TRANSPORT is
  deprecated". Mechanism: the code under test writes the process environment. serving_hook.handle_multimodal_feature_transport
  ends with envs.SGLANG_USE_CUDA_IPC_TRANSPORT.set("0"/"1") on every call; the tests of TestNoneMeansUnset reach it through
  ServerArgs resolution and leave the variable set; this test, unlike its neighbours (which call .clear() first), does not
  clear it, so it takes the "legacy variable is set" branch. Class of defect: process environment mutated by the code under
  test and not restored by the test.
