# DeepSeek V4.1 Flash — Phase 3a (eager three-tier streaming, full model, `G`/`f`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run the full 40-layer DeepSeek V4.1 Flash EXL3 model in our SGLang fork, **eagerly**, with routed experts streamed NVMe → bounded host-RAM cache → bounded VRAM slot cache, and Engram rows served through a bounded RAM cache. Check its logits against the reference oracle on the full model. Then measure the two numbers the whole design rests on: `G` (VRAM misses per token) and `f` (the share of those that also miss RAM).

**Architecture:**
- **Why 3a is eager, and why it comes first.** §9.4 says the design is NVMe-bound once `f` ≥ 25%, and Phase 1's 3-layer proxy puts `f` at about 34% (§15.2). The graph-mode miss mechanism (§9.3 options A/B/C) is the expensive, L-sized part of Phase 3. So 3a builds the cheapest thing that measures `G`, `f` and tok/s on the real model. The Exl3 MoE path is already eager-only (`exl3_moe_loop` host-syncs; `assert_not_capturing` guards it), so a synchronous miss fetch fits inside it. **3b** (the slot-indexed RAM tier read in-graph, the §9.3 miss mechanism with its failure path, CUDA graphs) is planned only after 3a's numbers clear the go/no-go bar (§12.1).
- **New streaming classes, not a retrofit of `ExpertStreamer`.** Our NVFP4 streamer assumes each named tensor is a dense `[num_experts, ...]` array whose row is one contiguous slice (`_validate_sources`, `ExpertPinnedHostCache`, `ExpertHotCache`). An EXL3 row is one packed 13,315,596 B blob of 12 tensors at per-expert file offsets. Four small classes sit on the Phase 0 layout primitives (`Exl3ExpertLayout`, `Exl3SlotLayout`, both currently unused):
  1. `Exl3RowReader`: one page-aligned (`O_DIRECT`) superset read per expert, straight from the original shards through the shared io_uring reader.
  2. `Exl3RamExpertCache`: bounded LRU of raw rows in page-aligned, CUDA-registered host memory. Each slot holds one superset read, so the row sits at a per-expert offset inside it. There is no padding tax in RAM (§14.1(c)).
  3. `Exl3VramExpertCache`: bounded LRU of padded 16 B-aligned slots. Each fill copies the 12 segments from the RAM row to their `Exl3SlotLayout` offsets, and yields `Exl3Tensors` views per slot. Eviction drops the row; RAM keeps its copy (§9.1, decided).
  4. `Exl3ExpertStreamRuntime`: one per process. It owns the tiers, resolves a layer's `topk_ids` into resident experts, keeps `G`/`f` counters, writes an optional per-call trace, and seeds the caches from router counts.
- **Inclusive hierarchy, enforced.** A RAM eviction never picks a row the VRAM tier holds (`is_pinned=vram.contains`), so VRAM ⊂ RAM holds by construction.
- **Loading the full model reads no expert bytes.** In streaming mode, `Exl3MoEMethod.create_weights` registers no per-expert parameters, so `load_weights` already skips them (the existing `skip_unmaterialized_expert_param` branch, `deepseek_v4.py:5330`). But the safetensors iterators call `get_tensor` on every name before `load_weights` sees it (`weight_utils.py:1161`, `:1252`). A `skip_name` predicate is added to both iterators and wired through `DefaultModelLoader.Source` from a model hook (`DeepseekV4ForCausalLM.skip_checkpoint_weight`).
- **Engram RAM cache.** An 8-way set-associative row cache (numpy) sits in front of `EngramFileTable`, shared by both Engram layers. Misses read through `PagedRowSource` with `O_DIRECT`, which gains a `base_offset` (the table does not start at byte 0 of its shard), so the page cache does not balloon past the RAM budget. The default stays off: the current `np.memmap` path is unchanged when `SGLANG_DSV41_ENGRAM_RAM_GIB` is 0.
- **The full-model oracle is now possible, and it makes the Phase 1 bar meaningful again.** `ref_oracle.py` already keeps routed experts as EXL3 and dequantizes them per call. A `--lazy-experts` mode reads each expert's tensors from the shard on use (plain `safe_open`, independent of the streaming code under test) instead of holding all of them on the GPU. The 3-layer oracle was accepted on a noise-floor ruling because its logits were flat (§15.2); a 40-layer model has sharp logits, so top-1 ≥ 0.98 and mean |Δlogprob| ≤ 0.05 apply as written, with the noise floor re-measured beside them.
- **`G`/`f` come from a trace, not a single live number.** The runtime logs `G`/`f` for the configured sizes. A replay simulator (`tier_sim.py`) evaluates other VRAM sizes (7.9%/10.0%/11.5%, §4) and a prefill-bypass policy offline, and emits the router-count file that seeds the caches (the "hot-cache seed", §11).

**Rulings made while writing this plan** (the executor records them in the ledger; each can be reversed later):
- **Dequantized EXL3 modules (§4, 2.8 GiB): keep them dense in 3a.** Removing them means per-call reconstruction of `wo_a` on every decode step, a latency cost 3a cannot measure until CUDA graphs exist. 3a's VRAM budget subtracts them. Revisit in 3b with a measured reconstruct cost.
- **`max_running_requests=4`, explicit, everywhere.** BS1 decode is what 3a measures; §4's pool-configurator check is satisfied the same way `compare_oracle.py` is.
- **The candidate indexer** (layer 20 publishes, layers 21+ consume) gets CPU tests now. The full-model run is its first sm_120 exercise, on the DeepGEMM sm_120 fork at index page 128, already wired (§15.1, `8709dde032`).
- **Shared expert pinning** is satisfied by running with `disable_shared_experts_fusion=True`: the shared expert is then a separate always-resident module. The runtime rejects a fused layout, because its expert count would not match the checkpoint's.

**Tech Stack:** Python 3.13, PyTorch 2.13 (cu130), our io_uring reader (`sglang.kernels.ops.io.uring_file_reader`), numpy, safetensors, exllamav3 extension (Phase 1), SGLang `Engine`, `fio`.

**Spec:** [`DSV41_REFERENCE.md`](../../../DSV41_REFERENCE.md) — §4, §5, §8, §9, §11 Phase 3, §12, §13, §14.1–14.2, §15. Read §9 and §15.2 before starting.

**Out of scope (3b and later):** CUDA-graph capture of the MoE path; any in-graph RAM or NVMe miss mechanism (§9.3); the fused `exl3_moe` kernel (Phase 2b); overlap scheduling; DSpark (Phase 4); vision; copying the experts to `/mnt/nvme1` (the owner does it; every path here takes the expert directory as a parameter).

## Facts this plan relies on (measured or read 2026-09-18)

- EXL3 routed expert row: 12 tensors in on-disk order `w1.{suh,svh,mul1,trellis}`, `w2.{…}`, `w3.{…}`, byte-contiguous, one shard each, 13,315,596 B. `w1`/`w3` are `[hidden=5120 → inter=2304]`, `w2` is `[2304 → 5120]`; trellis `I16 [in/16, out/16, 48]`; `suh F16[in]`, `svh F16[out]`, `mul1 I32[]` (always True, unused at compute). The 16 B slot layout is 13,315,632 B (`test_exl3_slot_layout.py`).
- `Exl3Tensors(trellis, suh, svh, mul1: bool)` validates dtype and shape only (`exl3_ops.py:38-63`). `exl3_moe_loop(x, topk_weights, topk_ids, w13, w2, swiglu_limit)` only needs `len(w2)` (bincount `minlength`) and `w13[e]` = `(gate=w1, up=w3)`, `w2[e]` for experts with a nonzero count (`exl3_ops.py:109-135`).
- `Exl3MoEMethod.apply` passes `layer.exl3_w13` / `layer.exl3_w2` (`exl3.py:298-330`); `FusedMoE.layer_id` is the decoder layer index (`fused_moe_triton/layer.py:361`, passed `layer_id=layer_id` from `deepseek_v2.py`).
- The shared io_uring reader: `shared_uring_file_reader()` (`model_loader/file_row_reader.py`), with `open(path, direct=) -> int`, `file_size(fid) -> int`, `read(file_ids, offsets, destinations, lengths) -> int` (four int64 CPU tensors; destinations are addresses). `O_DIRECT` needs page-aligned offsets, lengths and destinations; a read past end of file returns short.
- `_cuda_host_register(tensor, registration_granularity_bytes=...)` / `_cuda_host_unregister(tensor)` in `sglang.srt.mem_cache.pool_host.common`.
- `PagedRowSource(reader, path, row_bytes, row_count, *, direct)`; `read_rows(rows, destination)` places row `i` at file offset `rows[i] * row_bytes` (`file_row_reader.py:169-260`).
- `EngramFileTable(path, weight_key, scale_key, num_embeddings, dim, block=32)`; `open(table_dir, layer_id, num_embeddings, dim)`; `lookup(indices)` → bf16 `[*indices.shape, dim]` (`layers/engram_file_table.py`).
- The default weight iterator is `buffered_multi_thread_safetensors_weights_iterator` (`enable_multithread_load` defaults True, `loader.py:588`); the single-threaded one is `safetensors_weights_iterator`. Both are chosen in `DefaultModelLoader._get_weights_iterator` (`loader.py:657-684`). `Source.init_new(model_config, model)` reads optional model attributes (`loader.py:398-407`).

```python
"""A tiny EXL3 checkpoint on disk whose expert bytes are known (tests only).

Each shard starts with a 6-byte plain tensor so no expert row is page- or
16-byte-aligned in the file, as in the real export.
"""

from __future__ import annotations

import json
import os
import struct

import numpy as np

HIDDEN = 128
INTER = 128
BITS = 3


def expert_spec(hidden: int = HIDDEN, inter: int = INTER, bits: int = BITS):
    """[(suffix, dtype, shape, nbytes)] in on-disk order, as in the real export."""
    spec = []
    for w, (d_in, d_out) in (("w1", (hidden, inter)), ("w2", (inter, hidden)), ("w3", (hidden, inter))):
        spec += [
            (f"{w}.suh", "F16", (d_in,), 2 * d_in),
            (f"{w}.svh", "F16", (d_out,), 2 * d_out),
            (f"{w}.mul1", "I32", (), 4),
            (f"{w}.trellis", "I16", (d_in // 16, d_out // 16, 16 * bits), d_in * d_out * bits // 8),
        ]
    return spec


def expert_bytes(layer: int, expert: int, row_bytes: int) -> bytes:
    rng = np.random.default_rng(layer * 100_003 + expert)
    return rng.integers(0, 256, row_bytes, dtype=np.uint8).tobytes()


def _write_shard(path: str, tensors: list[tuple[str, str, tuple, bytes]]) -> None:
    header, offset = {}, 0
    for name, dtype, shape, data in tensors:
        header[name] = {"dtype": dtype, "shape": list(shape), "data_offsets": [offset, offset + len(data)]}
        offset += len(data)
    blob = json.dumps(header).encode()
    blob += b" " * (-len(blob) % 8)
    with open(path, "wb") as f:
        f.write(struct.pack("<Q", len(blob)))
        f.write(blob)
        for *_, data in tensors:
            f.write(data)


def write_fake_exl3(
    directory: str,
    num_layers: int,
    num_experts: int,
    experts_per_shard: int = 3,
    hidden: int = HIDDEN,
    inter: int = INTER,
) -> dict[tuple[int, int], bytes]:
    """Write shards plus model.safetensors.index.json; return each expert's raw row."""
    spec = expert_spec(hidden, inter)
    row_bytes = sum(nbytes for *_, nbytes in spec)
    keys = [(layer, expert) for layer in range(num_layers) for expert in range(num_experts)]
    rows, weight_map = {}, {}
    for shard_index, first in enumerate(range(0, len(keys), experts_per_shard)):
        filename = f"model-{shard_index + 1:05d}.safetensors"
        tensors = [(f"layers.{keys[first][0]}.attn.norm{shard_index}.weight", "BF16", (3,), b"\x01" * 6)]
        for layer, expert in keys[first : first + experts_per_shard]:
            row = expert_bytes(layer, expert, row_bytes)
            rows[(layer, expert)] = row
            cursor = 0
            for suffix, dtype, shape, nbytes in spec:
                name = f"layers.{layer}.ffn.experts.{expert}.{suffix}"
                tensors.append((name, dtype, shape, row[cursor : cursor + nbytes]))
                cursor += nbytes
        _write_shard(os.path.join(directory, filename), tensors)
        weight_map.update({name: filename for name, *_ in tensors})
    with open(os.path.join(directory, "model.safetensors.index.json"), "w") as f:
        json.dump({"weight_map": weight_map}, f)
    return rows
```

```python
"""Read whole EXL3 expert rows from the original shards, one aligned read each.

A row's file offset is not page-aligned, so each read covers the page-aligned
superset of the row and the caller finds the row at a per-expert offset inside
its buffer. That keeps O_DIRECT possible with no on-disk re-layout.
"""

from __future__ import annotations

from typing import TYPE_CHECKING, Optional, Sequence

import torch

from sglang.srt.layers.moe.exl3_expert_layout import Exl3ExpertLayout
from sglang.srt.model_loader.file_row_reader import PAGE_BYTES, shared_uring_file_reader

if TYPE_CHECKING:
    from sglang.kernels.ops.io.uring_file_reader import UringFileReader


class Exl3RowReader:
    def __init__(
        self,
        layout: Exl3ExpertLayout,
        reader: Optional[UringFileReader] = None,
        *,
        direct: bool = True,
    ) -> None:
        self.layout = layout
        self._reader = reader if reader is not None else shared_uring_file_reader()
        self._direct = direct
        self._files: dict[str, tuple[int, int]] = {}
        self.buffer_bytes = max(
            record.aligned_read(PAGE_BYTES)[1] for record in layout.records.values()
        )

    def _file(self, path: str) -> tuple[int, int]:
        entry = self._files.get(path)
        if entry is None:
            file_id = self._reader.open(path, direct=self._direct)
            entry = self._files[path] = (file_id, self._reader.file_size(file_id))
        return entry

    def read(self, keys: Sequence[tuple[int, int]], destinations: Sequence[int]) -> list[int]:
        """Read each expert into a page-aligned host address with room for
        ``buffer_bytes``; return where each row starts inside its buffer."""
        if len(keys) != len(destinations):
            raise ValueError("one destination per expert")
        if not keys:
            return []
        if any(address % PAGE_BYTES for address in destinations):
            raise ValueError("expert row destinations must be page-aligned")
        file_ids, offsets, lengths, starts = [], [], [], []
        expected = 0
        for key in keys:
            record = self.layout.records[key]
            offset, length, start = record.aligned_read(PAGE_BYTES)
            file_id, file_bytes = self._file(record.path)
            file_ids.append(file_id)
            offsets.append(offset)
            lengths.append(length)
            starts.append(start)
            # The superset of a shard's last row may run past end of file.
            expected += min(length, file_bytes - offset)
        actual = self._reader.read(
            torch.tensor(file_ids, dtype=torch.int64),
            torch.tensor(offsets, dtype=torch.int64),
            torch.tensor(list(destinations), dtype=torch.int64),
            torch.tensor(lengths, dtype=torch.int64),
        )
        if actual != expected:
            raise RuntimeError(f"EXL3 expert read ended early: read {actual} of {expected} bytes")
        return starts
```

```python
"""A bounded, least-recently-used host-RAM tier of raw EXL3 expert rows.

Each slot is page-aligned and holds one aligned superset read, so the row sits
at a per-expert offset inside it and RAM carries no padding (DSV41_REFERENCE
§14.1(c)). The VRAM tier copies from here; promotion keeps the RAM copy, and
``is_pinned`` keeps every VRAM-resident row in RAM, so the hierarchy stays
inclusive.
"""

from __future__ import annotations

from collections import OrderedDict
from typing import Callable, Iterable, Optional

import torch

from sglang.srt.layers.moe.exl3_row_reader import Exl3RowReader
from sglang.srt.model_loader.file_row_reader import PAGE_BYTES

Key = tuple[int, int]


class Exl3RamExpertCache:
    def __init__(
        self,
        reader: Exl3RowReader,
        capacity: int,
        *,
        register: bool = False,
        is_pinned: Optional[Callable[[Key], bool]] = None,
    ) -> None:
        if capacity <= 0:
            raise ValueError("RAM expert cache needs at least one slot")
        self.reader = reader
        self.capacity = capacity
        self.slot_bytes = self.slot_bytes_for(reader)
        self._storage = torch.empty(capacity * self.slot_bytes + PAGE_BYTES, dtype=torch.uint8)
        start = (-self._storage.data_ptr()) % PAGE_BYTES
        self.buffer = self._storage[start : start + capacity * self.slot_bytes].view(
            capacity, self.slot_bytes
        )
        if register:
            from sglang.srt.mem_cache.pool_host.common import _cuda_host_register

            _cuda_host_register(self.buffer, registration_granularity_bytes=self.slot_bytes)
        self._is_pinned = is_pinned or (lambda key: False)
        self._slots: OrderedDict[Key, tuple[int, int]] = OrderedDict()
        self._free = list(range(capacity - 1, -1, -1))
        self.hits = 0
        self.misses = 0

    @staticmethod
    def slot_bytes_for(reader: Exl3RowReader) -> int:
        return -(-reader.buffer_bytes // PAGE_BYTES) * PAGE_BYTES

    def contains(self, key: Key) -> bool:
        return key in self._slots

    def ensure(self, keys: Iterable[Key]) -> list[torch.Tensor]:
        keys = list(keys)
        distinct = list(dict.fromkeys(keys))
        if len(distinct) > self.capacity:
            raise ValueError(
                f"{len(distinct)} experts in one batch exceed the RAM cache capacity {self.capacity}"
            )
        protected = set(distinct)
        missing = []
        for key in distinct:
            if key in self._slots:
                self._slots.move_to_end(key)
                self.hits += 1
            else:
                missing.append(key)
        if missing:
            slots = [self._take_slot(protected) for _ in missing]
            try:
                starts = self.reader.read(missing, [self.buffer[slot].data_ptr() for slot in slots])
            except BaseException:
                self._free.extend(slots)
                raise
            for key, slot, start in zip(missing, slots, starts):
                self._slots[key] = (slot, start)
            self.misses += len(missing)
        row_bytes = self.reader.layout.row_bytes
        out = []
        for key in keys:
            slot, start = self._slots[key]
            out.append(self.buffer[slot, start : start + row_bytes])
        return out

    def _take_slot(self, protected: set[Key]) -> int:
        if self._free:
            return self._free.pop()
        for key in self._slots:  # oldest first
            if key not in protected and not self._is_pinned(key):
                slot, _ = self._slots.pop(key)
                return slot
        raise RuntimeError("RAM expert cache: every slot is pinned or in use by this batch")
```

```python
"""A bounded, least-recently-used VRAM tier of padded EXL3 expert slots.

Each slot re-places the row's 12 tensors at 16-byte-aligned offsets
(``Exl3SlotLayout``) so exllamav3's kernels can load them; the copy from the
RAM row does the padding (DSV41_REFERENCE §14.1(c)). Eviction drops the slot;
the RAM tier still holds the row.
"""

from __future__ import annotations

from collections import OrderedDict
from typing import Callable, Iterable

import torch

from sglang.srt.layers.moe.exl3_expert_layout import Exl3ExpertLayout
from sglang.srt.layers.moe.exl3_slot_layout import build_exl3_slot_layout
from sglang.srt.layers.quantization.exl3_ops import Exl3Tensors

Key = tuple[int, int]
ExpertViews = tuple[tuple[Exl3Tensors, Exl3Tensors], Exl3Tensors]

_DTYPES = {"I16": torch.int16, "F16": torch.float16, "I32": torch.int32}


class Exl3VramExpertCache:
    def __init__(
        self, layout: Exl3ExpertLayout, capacity: int, device: torch.device, alignment: int = 16
    ) -> None:
        if capacity <= 0:
            raise ValueError("VRAM expert cache needs at least one slot")
        self.layout = layout
        self.slot_layout = build_exl3_slot_layout(layout.tensors, alignment)
        self._spans = {span.name: span for span in layout.tensors}
        self.capacity = capacity
        self.buffer = torch.empty((capacity, self.slot_layout.slot_bytes), dtype=torch.uint8, device=device)
        self._slots: OrderedDict[Key, int] = OrderedDict()
        self._free = list(range(capacity - 1, -1, -1))
        self._views: dict[int, ExpertViews] = {}
        self.hits = 0
        self.misses = 0

    @staticmethod
    def slot_bytes_for(layout: Exl3ExpertLayout, alignment: int = 16) -> int:
        return build_exl3_slot_layout(layout.tensors, alignment).slot_bytes

    def contains(self, key: Key) -> bool:
        return key in self._slots

    def ensure(
        self, keys: Iterable[Key], host_rows: Callable[[list[Key]], list[torch.Tensor]]
    ) -> dict[Key, ExpertViews]:
        distinct = list(dict.fromkeys(keys))
        if len(distinct) > self.capacity:
            raise ValueError(
                f"{len(distinct)} experts in one batch exceed the VRAM cache capacity {self.capacity}"
            )
        protected = set(distinct)
        missing = []
        for key in distinct:
            if key in self._slots:
                self._slots.move_to_end(key)
                self.hits += 1
            else:
                missing.append(key)
        if missing:
            rows = host_rows(missing)
            for key, row in zip(missing, rows):
                slot = self._take_slot(protected)
                self._fill(slot, row)
                self._slots[key] = slot
            self.misses += len(missing)
            if self.buffer.is_cuda:
                # The RAM slots these rows came from may be overwritten by the next
                # read, so the copies must land before control returns.
                torch.cuda.current_stream(self.buffer.device).synchronize()
        return {key: self._views_of(self._slots[key]) for key in distinct}

    def _take_slot(self, protected: set[Key]) -> int:
        if self._free:
            return self._free.pop()
        for key in self._slots:  # oldest first
            if key not in protected:
                return self._slots.pop(key)
        raise RuntimeError("VRAM expert cache: every slot is in use by this batch")

    def _fill(self, slot: int, row: torch.Tensor) -> None:
        destination = self.buffer[slot]
        for segment in self.slot_layout.segments:
            destination[segment.dst_offset : segment.dst_offset + segment.nbytes].copy_(
                row[segment.src_offset : segment.src_offset + segment.nbytes], non_blocking=True
            )

    def _tensor(self, slot: int, name: str) -> torch.Tensor:
        span = self._spans[name]
        offset = self.slot_layout.dst_offset(name)
        raw = self.buffer[slot, offset : offset + span.nbytes]
        return raw.view(_DTYPES[span.dtype]).view(span.shape)

    def _views_of(self, slot: int) -> ExpertViews:
        views = self._views.get(slot)
        if views is None:

            def tensors(w: str) -> Exl3Tensors:
                return Exl3Tensors(
                    trellis=self._tensor(slot, f"{w}.trellis"),
                    suh=self._tensor(slot, f"{w}.suh"),
                    svh=self._tensor(slot, f"{w}.svh"),
                    mul1=True,
                )

            views = self._views[slot] = ((tensors("w1"), tensors("w3")), tensors("w2"))
        return views
```

The views cached per slot stay valid across refills, because a slot's address and layout never change; only its bytes do.

```python
"""The process-wide EXL3 expert streaming runtime (eager).

It resolves one MoE layer's routed experts into resident VRAM slots: a VRAM
miss is served from the host-RAM tier, and a RAM miss is read from the shards
first, all synchronously. Counters give the two numbers the design rests on
(DSV41_REFERENCE §9.4): G, VRAM misses per decode token, and f, the share of
those that also miss RAM.
"""

from __future__ import annotations

import json
import logging
import threading
import time
from typing import Optional, Sequence

import numpy as np
import torch

from sglang.srt.environ import envs
from sglang.srt.layers.moe.exl3_expert_layout import Exl3ExpertLayout, build_exl3_expert_layout
from sglang.srt.layers.moe.exl3_ram_cache import Exl3RamExpertCache
from sglang.srt.layers.moe.exl3_row_reader import Exl3RowReader
from sglang.srt.layers.moe.exl3_vram_cache import Exl3VramExpertCache
from sglang.srt.layers.quantization.exl3_ops import assert_not_capturing

logger = logging.getLogger(__name__)

_GIB = 1 << 30
_LOG_EVERY_FORWARDS = 256
_SEED_CHUNK = 256


class _Resident(Sequence):
    """``len`` = experts per layer; indexing reaches only this call's experts."""

    def __init__(self, num_experts: int, table: dict, index: int) -> None:
        self._n, self._table, self._index = num_experts, table, index

    def __len__(self) -> int:
        return self._n

    def __getitem__(self, expert: int):
        return self._table[expert][self._index]


class Exl3ExpertStreamRuntime:
    def __init__(
        self,
        layout: Exl3ExpertLayout,
        ram: Exl3RamExpertCache,
        vram: Exl3VramExpertCache,
        trace_path: str = "",
    ) -> None:
        self.layout, self.ram, self.vram = layout, ram, vram
        self._trace = open(trace_path, "a") if trace_path else None
        self._last_layer: Optional[int] = None
        self._forward_is_decode = False
        self.forwards = 0
        self.decode_tokens = 0
        self.decode_vram_misses = 0
        self.decode_ram_misses = 0

    @classmethod
    def from_env(cls, device: torch.device) -> Exl3ExpertStreamRuntime:
        expert_dir = envs.SGLANG_DSV41_EXPERT_DIR.get()
        if not expert_dir:
            raise ValueError("SGLANG_DSV41_EXPERT_STREAM needs SGLANG_DSV41_EXPERT_DIR")
        layout = build_exl3_expert_layout(expert_dir)
        vram_capacity = int(
            envs.SGLANG_DSV41_EXPERT_VRAM_GIB.get() * _GIB // Exl3VramExpertCache.slot_bytes_for(layout)
        )
        vram = Exl3VramExpertCache(layout, vram_capacity, device)
        reader = Exl3RowReader(layout)
        ram_capacity = int(
            envs.SGLANG_DSV41_EXPERT_RAM_GIB.get() * _GIB // Exl3RamExpertCache.slot_bytes_for(reader)
        )
        started = time.perf_counter()
        ram = Exl3RamExpertCache(
            reader, ram_capacity, register=device.type == "cuda", is_pinned=vram.contains
        )
        logger.info(
            "exl3 expert stream: %d VRAM slots (%.1f GiB), %d RAM slots (%.1f GiB, "
            "allocated and registered in %.1f s), experts from %s",
            vram_capacity, vram_capacity * vram.slot_layout.slot_bytes / _GIB,
            ram_capacity, ram_capacity * ram.slot_bytes / _GIB,
            time.perf_counter() - started, expert_dir,
        )
        runtime = cls(layout, ram, vram, envs.SGLANG_DSV41_EXPERT_TRACE_PATH.get())
        seed_path = envs.SGLANG_DSV41_EXPERT_SEED_PATH.get()
        if seed_path:
            with open(seed_path) as f:
                runtime.seed(np.asarray(json.load(f)["counts"]))
        return runtime

    def resolve(self, layer_id: int, topk_ids: torch.Tensor):
        assert_not_capturing("Exl3ExpertStreamRuntime.resolve")
        tokens = int(topk_ids.shape[0])
        if self._last_layer is None or layer_id <= self._last_layer:
            self.forwards += 1
            self._forward_is_decode = tokens == 1
            if self._forward_is_decode:
                self.decode_tokens += 1
            if self.forwards % _LOG_EVERY_FORWARDS == 0:
                logger.info("exl3 expert stream: %s", json.dumps(self.stats()))
        self._last_layer = layer_id

        flat = topk_ids.reshape(-1)
        experts = torch.unique(flat[flat >= 0]).tolist()
        keys = [(layer_id, expert) for expert in experts]
        vram_before, ram_before = self.vram.misses, self.ram.misses
        views = self.vram.ensure(keys, self.ram.ensure)
        vram_miss = self.vram.misses - vram_before
        ram_miss = self.ram.misses - ram_before
        if tokens == 1:
            self.decode_vram_misses += vram_miss
            self.decode_ram_misses += ram_miss
        if self._trace is not None:
            self._trace.write(
                json.dumps(
                    {"forward": self.forwards, "layer": layer_id, "tokens": tokens,
                     "experts": experts, "vram_miss": vram_miss, "ram_miss": ram_miss}
                )
                + "\n"
            )
        table = {expert: views[(layer_id, expert)] for expert in experts}
        n = self.layout.num_experts
        return _Resident(n, table, 0), _Resident(n, table, 1)

    def seed(self, counts: np.ndarray) -> None:
        """Load the most-used experts: the top RAM-capacity keys into RAM, then the
        top VRAM-capacity keys into VRAM. Not counted as traffic."""
        order = np.argsort(-counts, axis=None, kind="stable")
        keys = [tuple(int(v) for v in np.unravel_index(i, counts.shape)) for i in order]
        saved = (self.vram.hits, self.vram.misses, self.ram.hits, self.ram.misses)
        ram_keys = keys[: self.ram.capacity]
        for start in range(0, len(ram_keys), _SEED_CHUNK):
            self.ram.ensure(ram_keys[start : start + _SEED_CHUNK])
        vram_keys = keys[: min(self.vram.capacity, self.ram.capacity)]
        for start in range(0, len(vram_keys), _SEED_CHUNK):
            self.vram.ensure(vram_keys[start : start + _SEED_CHUNK], self.ram.ensure)
        self.vram.hits, self.vram.misses, self.ram.hits, self.ram.misses = saved

    def stats(self) -> dict:
        return {
            "forwards": self.forwards,
            "decode_tokens": self.decode_tokens,
            "decode_vram_misses": self.decode_vram_misses,
            "decode_ram_misses": self.decode_ram_misses,
            "G": self.decode_vram_misses / self.decode_tokens if self.decode_tokens else 0.0,
            "f": self.decode_ram_misses / self.decode_vram_misses if self.decode_vram_misses else 0.0,
            "vram_hits": self.vram.hits,
            "vram_misses": self.vram.misses,
            "ram_hits": self.ram.hits,
            "ram_misses": self.ram.misses,
        }

    def close(self) -> None:
        if self._trace is not None:
            self._trace.close()
            self._trace = None


_RUNTIME: Optional[Exl3ExpertStreamRuntime] = None
_RUNTIME_LOCK = threading.Lock()


def get_exl3_stream_runtime(device: torch.device) -> Exl3ExpertStreamRuntime:
    global _RUNTIME
    with _RUNTIME_LOCK:
        if _RUNTIME is None:
            _RUNTIME = Exl3ExpertStreamRuntime.from_env(device)
        return _RUNTIME
```

How `test_decode_counters_give_G_and_f` adds up, with VRAM holding 3 slots:
- After forward 1, VRAM holds `(0,0)`, `(0,1)` and `(1,2)`.
- Forward 2's layer-0 call hits both of its experts.
- Its layer-1 call hits `(1,2)` and misses `(1,0)`, which evicts `(0,0)`, the oldest slot not in use by the call.
- That makes 4 VRAM misses, all of them RAM misses (RAM has free slots throughout), over 2 decode tokens.

```python
"""A set-associative host-RAM cache of Engram rows (weight bytes + scale bytes).

Row ids are n-gram hashes, so ``id % n_sets`` spreads them evenly; eight
least-recently-used ways per set track exact LRU closely at a fraction of the
memory an exact LRU map over ~19M rows would need (DSV41_REFERENCE §5).
"""

from __future__ import annotations

import threading
from typing import Callable, Optional

import numpy as np

from sglang.srt.environ import envs

_GIB = 1 << 30


class EngramRowCache:
    def __init__(self, capacity_rows: int, row_bytes: int, ways: int = 8) -> None:
        self.ways = ways
        self.n_sets = max(1, capacity_rows // ways)
        self.row_bytes = row_bytes
        self.tags = np.full((self.n_sets, ways), -1, dtype=np.int64)
        self.ages = np.zeros((self.n_sets, ways), dtype=np.int64)
        self.data = np.zeros((self.n_sets * ways, row_bytes), dtype=np.uint8)
        self.clock = 0
        self.accesses = 0
        self.hits = 0

    @classmethod
    def for_bytes(cls, budget_bytes: int, row_bytes: int) -> EngramRowCache:
        return cls(budget_bytes // row_bytes, row_bytes)

    def lookup(self, keys: np.ndarray, fetch: Callable[[np.ndarray], np.ndarray]) -> np.ndarray:
        keys = np.asarray(keys, dtype=np.int64).reshape(-1)
        self.clock += 1
        self.accesses += keys.size
        unique, inverse = np.unique(keys, return_inverse=True)
        sets = unique % self.n_sets
        match = self.tags[sets] == unique[:, None]
        hit = match.any(axis=1)
        way = match.argmax(axis=1)
        out = np.empty((unique.size, self.row_bytes), dtype=np.uint8)
        out[hit] = self.data[sets[hit] * self.ways + way[hit]]
        self.ages[sets[hit], way[hit]] = self.clock
        miss = ~hit
        if miss.any():
            rows = fetch(unique[miss])
            out[miss] = rows
            for key, s, row in zip(unique[miss], sets[miss], rows):
                w = int(self.ages[s].argmin())
                self.tags[s, w] = key
                self.ages[s, w] = self.clock
                self.data[s * self.ways + w] = row
        self.hits += int(np.count_nonzero(hit[inverse]))
        return out[inverse]


_SHARED: Optional[EngramRowCache] = None
_SHARED_LOCK = threading.Lock()


def shared_engram_row_cache(row_bytes: int) -> Optional[EngramRowCache]:
    """One cache for every Engram layer, sized by SGLANG_DSV41_ENGRAM_RAM_GIB."""
    global _SHARED
    budget = envs.SGLANG_DSV41_ENGRAM_RAM_GIB.get()
    if budget <= 0:
        return None
    with _SHARED_LOCK:
        if _SHARED is None:
            _SHARED = EngramRowCache.for_bytes(int(budget * _GIB), row_bytes)
        elif _SHARED.row_bytes != row_bytes:
            raise ValueError(f"Engram layers disagree on row bytes: {_SHARED.row_bytes} vs {row_bytes}")
        return _SHARED
```

```python
"""Replay an EXL3 expert-stream trace through inclusive VRAM/RAM LRU tiers.

G = VRAM misses per decode token, f = the share of those that also miss RAM
(DSV41_REFERENCE §9.4). VRAM evicts by dropping; RAM is touched only on a VRAM
miss and never evicts a row VRAM holds, exactly like Exl3ExpertStreamRuntime.
"""

from __future__ import annotations

import argparse
import json
from collections import OrderedDict

import numpy as np

LINK_MS = 1.11
NVME_MS = {"nvme2": 7.0, "x4": 3.4}


def load_trace(path: str) -> list[dict]:
    with open(path) as f:
        return [json.loads(line) for line in f if line.strip()]


def simulate(calls, vram_slots: int, ram_slots: int, *, prefill_bypass: bool = False) -> dict:
    vram: OrderedDict = OrderedDict()
    ram: OrderedDict = OrderedDict()
    decode_forwards, vram_misses, ram_misses = set(), 0, 0

    def ram_touch(key) -> bool:
        if key in ram:
            ram.move_to_end(key)
            return True
        if len(ram) >= ram_slots:
            victim = next((k for k in ram if k not in vram), None)
            if victim is None:
                raise RuntimeError("every RAM row is VRAM-resident; RAM must exceed VRAM")
            del ram[victim]
        ram[key] = None
        return False

    for call in calls:
        decode = call["tokens"] == 1
        if decode:
            decode_forwards.add(call["forward"])
        if not decode and prefill_bypass:
            continue
        keys = [(call["layer"], e) for e in call["experts"]]
        protected = set(keys)
        for key in keys:
            if key in vram:
                vram.move_to_end(key)
                continue
            ram_hit = ram_touch(key)
            if decode:
                vram_misses += 1
                ram_misses += 0 if ram_hit else 1
            if len(vram) >= vram_slots:
                victim = next(k for k in vram if k not in protected)
                del vram[victim]
            vram[key] = None
    tokens = len(decode_forwards)
    return {
        "decode_tokens": tokens,
        "vram_misses": vram_misses,
        "ram_misses": ram_misses,
        "G": vram_misses / tokens if tokens else 0.0,
        "f": ram_misses / vram_misses if vram_misses else 0.0,
    }


def counts_from_trace(calls, num_layers: int, num_experts: int) -> np.ndarray:
    counts = np.zeros((num_layers, num_experts), dtype=np.int64)
    for call in calls:
        if call["tokens"] == 1:
            for expert in call["experts"]:
                counts[call["layer"], expert] += 1
    return counts


def main() -> None:
    p = argparse.ArgumentParser()
    p.add_argument("trace")
    p.add_argument("--vram-slots", type=int, nargs="+", default=[1220, 1540, 1770])
    p.add_argument("--ram-slots", type=int, nargs="+", default=[5630])
    p.add_argument("--emit-counts")
    p.add_argument("--num-layers", type=int, default=40)
    p.add_argument("--num-experts", type=int, default=384)
    args = p.parse_args()
    calls = load_trace(args.trace)
    rows = []
    for vram in args.vram_slots:
        for ram in args.ram_slots:
            for bypass in (False, True):
                r = simulate(calls, vram, ram, prefill_bypass=bypass)
                r.update({"vram_slots": vram, "ram_slots": ram, "prefill_bypass": bypass})
                for drive, t in NVME_MS.items():
                    r[f"ms_per_token_{drive}"] = r["G"] * LINK_MS + r["f"] * r["G"] * t
                rows.append(r)
    print(json.dumps({"trace": args.trace, "calls": len(calls), "rows": rows}, indent=2))
    if args.emit_counts:
        counts = counts_from_trace(calls, args.num_layers, args.num_experts)
        with open(args.emit_counts, "w") as f:
            json.dump({"counts": counts.tolist()}, f)


if __name__ == "__main__":
    main()
```

```python
"""Random EXL3 expert reads through Exl3RowReader: GB/s and ms/expert per batch size."""

from __future__ import annotations

import argparse
import json
import random
import time

import torch

from sglang.srt.layers.moe.exl3_expert_layout import build_exl3_expert_layout
from sglang.srt.layers.moe.exl3_row_reader import Exl3RowReader
from sglang.srt.model_loader.file_row_reader import PAGE_BYTES


def run(expert_dir: str, reads: int, batch: int, seed: int = 0, direct: bool = True) -> dict:
    layout = build_exl3_expert_layout(expert_dir)
    reader = Exl3RowReader(layout, direct=direct)
    slot = -(-reader.buffer_bytes // PAGE_BYTES) * PAGE_BYTES
    storage = torch.empty(batch * slot + PAGE_BYTES, dtype=torch.uint8)
    base = storage.data_ptr() + (-storage.data_ptr()) % PAGE_BYTES
    keys = random.Random(seed).choices(sorted(layout.records), k=reads)
    started = time.perf_counter()
    for start in range(0, reads, batch):
        chunk = keys[start : start + batch]
        reader.read(chunk, [base + i * slot for i in range(len(chunk))])
    seconds = time.perf_counter() - started
    return {
        "batch": batch,
        "reads": reads,
        "seconds": seconds,
        "gb_per_s": reads * layout.row_bytes / seconds / 1e9,
        "ms_per_expert": seconds * 1e3 / reads,
    }


def main() -> None:
    p = argparse.ArgumentParser()
    p.add_argument("--expert-dir", required=True)
    p.add_argument("--reads", type=int, default=512)
    p.add_argument("--batch", type=int, nargs="+", default=[1, 4, 8, 16, 32])
    p.add_argument("--buffered", action="store_true")
    args = p.parse_args()
    for batch in args.batch:
        print(json.dumps(run(args.expert_dir, args.reads, batch, direct=not args.buffered)), flush=True)


if __name__ == "__main__":
    main()
```

```python
"""Run corpus first turns through the streamed full model and time each session.

Set SGLANG_DSV41_EXPERT_STREAM / _DIR / _TRACE_PATH (and the Engram knobs) in
the environment; this script only drives the Engine and records timings.

from __future__ import annotations

import argparse
import json
import time


def _first_turns(path: str, n: int):
    with open(path) as f:
        for i, line in enumerate(f):
            if i >= n:
                return
            yield json.loads(line)["turns"][0]


def main() -> None:
    p = argparse.ArgumentParser()
    p.add_argument("--model", required=True)
    p.add_argument("--sessions", required=True)
    p.add_argument("--n", type=int, default=16)
    p.add_argument("--prompt-tokens", type=int, default=512)
    p.add_argument("--new-tokens", type=int, default=128)
    p.add_argument("--out", required=True)
    p.add_argument("--mem-fraction-static", type=float, default=0.85)
    p.add_argument("--chunked-prefill-size", type=int, default=512)
    args = p.parse_args()

    import sglang
    from transformers import AutoTokenizer

    tokenizer = AutoTokenizer.from_pretrained(args.model)
    engine = sglang.Engine(
        model_path=args.model,
        tp_size=1,
        disable_cuda_graph=True,
        disable_shared_experts_fusion=True,
        context_length=4096,
        mem_fraction_static=args.mem_fraction_static,
        chunked_prefill_size=args.chunked_prefill_size,
        # BS1 decode is what Phase 3a measures; DSV4 reserves SWA slots per request.
        max_running_requests=4,
    )
    sessions = []
    for text in _first_turns(args.sessions, args.n):
        ids = tokenizer(text).input_ids[: args.prompt_tokens]
        started = time.perf_counter()
        first = None
        chunks = 0
        for _chunk in engine.generate(
            input_ids=ids,
            sampling_params={"max_new_tokens": args.new_tokens, "temperature": 0},
            stream=True,
        ):
            chunks += 1
            if first is None:
                first = time.perf_counter()
        done = time.perf_counter()
        decode_s = done - first
        sessions.append(
            {
                "prompt_tokens": len(ids),
                "new_tokens": args.new_tokens,
                "ttft_s": first - started,
                "decode_tok_s": (args.new_tokens - 1) / decode_s if decode_s > 0 else 0.0,
            }
        )
        print(json.dumps(sessions[-1]), flush=True)
    engine.shutdown()
    report = {
        "per_session": sessions,
        "mean_decode_tok_s": sum(s["decode_tok_s"] for s in sessions) / len(sessions),
    }
    with open(args.out, "w") as f:
        json.dump(report, f, indent=2)
```
